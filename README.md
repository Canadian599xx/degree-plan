These are the courses in your plan that the catalog lists as offered in **only one term**. With a Fall 2028 finish there is **no spare semester**, so missing a make-or-break one pushes graduation to Spring 2029 or later.

| Course      | Only Offered | Must Happen           | Why It's Critical                                                                                                                                  |
| ----------- | ------------ | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CS 3433** | Fall         | **Fall 2027 (Sem 5)** | **Make-or-break.** Gates CS 4353 — the last piece of your concentration depends on this one class landing on time.                                 |
| **CS 4353** | Spring       | Spring 2028 (Sem 6)   | **Make-or-break.** Needs CS 3433 done first. Missing it means Spring 2029.                                                                         |
| **CS 4653** | Spring       | Spring 2028 (Sem 6)   | **Make-or-break.** Pushed back from Spring 2027. Prereq already satisfied (CS 3113), so it only needs a Spring seat. Missing it means Spring 2029. |

**Only three classes can actually cost you the Fall 2028 date: CS 3433, CS 4353, CS 4653.** Everything else is a swappable elective with Fall 2028 as a buffer.

**Practical advice:**

- **Register for CS 3433 the moment registration opens** for Fall 2027 — it also needs instructor consent, so request that early too.
- CS 4653 has already slipped once, so grab it early for Spring 2028. If it can't be scheduled again, ask your advisor now whether another concentration-eligible course can substitute, rather than finding out in Spring 2029.
- Prefer electives offered in **both Fall and Spring** — if a Spring 2028 seat falls through, you can retake the slot in Fall 2028 instead of losing the date.
- **Double-check GEO 1033's offering term** with your advisor or the course catalog — I only have confirmed data for CS courses.
- Run a degree audit with your advisor after Spring 2028 registration. UTSA generally also requires a minimum number of upper-division hours; your remaining 14 major classes are all upper-division, so you should be well over, but confirm.
